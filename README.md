# Ponnivalavan Mageskumar — Portfolio Website

**Digital Marketing Specialist | Data Analyst | AI & ML | Content Creator**

A modern, high-performance portfolio website built with **Next.js (App Router)**, **Tailwind CSS**, and **Framer Motion**, featuring a dark SaaS analytics aesthetic, interactive marketing command center, live KPI dashboards, custom project case studies, and a dedicated resume section.

---

## 🚀 Key Features

- **Hero & Command Center**: Interactive live-style marketing telemetry (ROAS 4.8x, Conversion Rate 5.84%, CTR 4.12%, CPA $18.20) with dynamic role cycler.
- **Toolkit Marquee**: Continuous horizontal marquee showcasing Google Ads, Meta Ads, GA4, GSC, SEMrush, Power BI, Tableau, SQL, Excel, Sheets, Canva, YouTube, and LinkedIn.
- **Two-Column About**: Detailed narrative and animated count-up statistics (5+ Years Experience, 20+ Projects, 50+ Campaigns, 100+ Reports).
- **Core Skills**: 7 categorized glassmorphism cards with progress bars and instant search filtering.
- **Analytics Showcase ("Turning Data Into Decisions")**: Interactive SVG charts covering Revenue Trends, Conversion Funnel, Traffic Sources, and Campaign Performance.
- **6 Featured Projects**: In-depth case studies with interactive modals and KPI impact metrics.
- **6 Services & Deliverables**: Full-funnel growth offerings.
- **6-Stage Analytics Workflow**: Collect → Clean → Analyze → Visualize → Optimize → Decide.
- **Experience Timeline**: 5+ years milestone breakdown with full responsibilities.
- **Dedicated Resume Section**: View and download options for `Ponnivalavan-Resume.pdf`.
- **Contact & Footer**: Validated contact form, direct social channels, and responsive design.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Effects**: [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti)

## 📦 Getting Started

### 1. Install dependencies
```bash
npm install
```

### 2. Run development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build
```bash
npm run build
npm start
```
